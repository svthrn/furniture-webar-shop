# Интерактивный WebAR-каталог мебели

Курсовая работа: веб-каталог мебели с 3D-просмотром и примеркой в дополненной реальности (WebAR). Чистый HTML + CSS + Vanilla JS, без сборщиков и Node.js — сайт работает локально и на GitHub Pages по HTTPS.

## Структура

```
index.html                     каталог: поиск, фильтр по категории и цене
css/style.css                  оформление
js/app.js                      логика каталога, фильтров и карточки товара
data/catalog.json              данные о товарах (3 позиции)
scripts/generate_sample_models.py  генератор примерных GLB-моделей
assets/models/*.glb            лёгкие модели мебели в реальном масштабе (метры)
```

## Возможности

- каталог с поиском по названию, фильтром по категории и по максимальной цене;
- карточка товара с `<model-viewer>` (`@google/model-viewer` v4): вращение, автоповорот, тени;
- кнопка «Поставить в комнате»: AR через WebXR / Scene Viewer (Android) и Quick Look (iOS);
- переключение цветовых вариантов (перекраска PBR-материала модели через API `<model-viewer>`);
- кнопка «Показать габариты» с размерами Ш×Г×В в сантиметрах.

## Локальный запуск

Из корня репозитория:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000/>. Запускать через `file://` нельзя: `fetch("data/catalog.json")` требует HTTP.

## Перегенерация моделей

```bash
python3 scripts/generate_sample_models.py
```

Скрипт не требует зависимостей: собирает GLB напрямую из примитивов и складывает файлы в `assets/models/`.

## Публикация на GitHub Pages

Settings → Pages → Source: ветка `main`, папка `/ (root)`. По HTTPS WebAR работает на смартфоне; AR обычно требует защищённого соединения.

## Замечания

- Формат `.usdz` для iOS Quick Look не генерируется этим скриптом: для него нужен конвертер (например, `usdzconvert`). Пока файл отсутствует, поле `ios_src` в `data/catalog.json` можно удалить — на Android AR продолжит работать.
- Модели примерные (примитивы), размеры совпадают с габаритами в `data/catalog.json`.
